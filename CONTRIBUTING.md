# Contributing to ChatGPT MCP App Starter

Thanks for helping improve this community-maintained TypeScript MCP Apps starter.

## Scope

Keep the default example small, self-hostable, beginner-friendly and compatible with the demonstrated `thread` and `global` entrypoints. Do not introduce paid services, API keys, scraping, persistent databases or large frameworks without a clear need.

## Propose a change

1. Open an issue explaining the problem or requested improvement.
2. Create a branch and make a focused change.
3. Run `npm install`, `npm run typecheck` and `npm run build`.
4. Open a pull request with steps to reproduce or verify the change.

Please avoid introducing hardcoded personal MCP server URLs, tracking, or undocumented dependencies. Update docs if the plugin setup flow changes.
