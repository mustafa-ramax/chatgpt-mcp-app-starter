# Security policy

This repository is a read-only public-data Hello World example, not a production security framework.

Avoid sharing credentials or sensitive user data in issues. If you find a security vulnerability in the starter, open a private GitHub security advisory for the repository owner if that feature is available. For a deployed fork, contact that deployment operator.

The source does not require API keys or user authentication. Anyone operating a public endpoint is responsible for assessing abuse, rate limits, third-party service terms, and appropriate authentication before adding sensitive tools.
